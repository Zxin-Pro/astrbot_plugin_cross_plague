# astrbot_plugin_cross_plague 🦠

跨群瘟疫模拟游戏插件（AstrBot）。感染会在不同群之间通过群友的**跨群发言**传播，群友需要合作研发解药、对抗随机突变事件，最终驱散全服疫情。

> ⚠️ **隐私说明**：本插件会记录群消息的**群号 / 用户 ID / 发言时间戳**，用于模拟跨群传播；**不记录任何消息内容**。

## 玩法

- 每天 `10:00`（可配置）系统随机挑选一个活跃群作为**零号病人**，瘟疫爆发
- 群友在感染群发言后去其他群发言，有 30%~50% 概率把瘟疫传过去
- 感染群健康值每小时 -5（重症 -10），归零转入**重症**
- 群友用 `/瘟疫研发` 贡献解药进度，攒满 100% 全群痊愈并获得 **7 天免疫**
- 每天 1 个随机用户成为**超级传播者**（传播概率 90%，一次可感染 3 个群）
- 每天随机触发一个全局事件：病毒变异 / 疫苗突破 / 群体免疫 / 封城 / 谣言四起
- 所有事件与日报文案由 LLM 生成新闻播报风格，LLM 不可用时自动降级本地模板

## 指令（全中文）

| 指令 | 说明 |
|---|---|
| `/瘟疫状态` | 查看本群疫情卡片（健康值/解药进度/感染时长/贡献榜 Top5） |
| `/瘟疫全服` | 全服疫情地图（按状态标色的群点位图） |
| `/瘟疫研发` | 为本群研发解药（随机贡献 1~5 点，每人每日上限 20 点） |
| `/瘟疫隔离` | 本群隔离 24 小时（不传也不被传，健康值仍衰减） |
| `/瘟疫排行榜` | 痊愈最快 / 感染最久 / 解药贡献 Top10 |
| `/瘟疫日报` | 查看今日瘟疫日报（LLM 新闻稿风格） |
| `/瘟疫退出` | 本群退出瘟疫模拟（管理员） |
| `/瘟疫帮助` | 帮助 |
| `/瘟疫重置` | 重置全服瘟疫（管理员） |
| `/瘟疫投放 <群号>` | 手动投放零号病人（管理员） |
| `/瘟疫清除 <群号>` | 手动清除某群感染（管理员） |

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| auto_start_enabled | true | 每日自动投放零号病人 |
| auto_start_time | "10:00" | 零号投放时间 |
| daily_report_time | "21:00" | 日报推送时间 |
| push_target | "" | 日报推送目标群号（逗号分隔，留空推全部活跃群） |
| spread_cooldown_hours | 1 | 同一用户传播判定冷却（小时） |
| enable_super_spreader | true | 启用超级传播者 |
| notify_daily_limit | 3 | 每群每日瘟疫通知上限（防刷屏） |
| speaking_research_chance | 8 | 感染群内发言助力研发概率（%） |
| immunity_days | 7 | 痊愈免疫天数 |

## 安装

```bash
# 在 AstrBot 插件市场搜索，或：
git clone https://github.com/Zxin-Pro/astrbot_plugin_cross_plague addons/plugins/astrbot_plugin_cross_plague
```

依赖：`aiosqlite`、`Pillow`（安装插件后自动 pip 安装）。

## 特性

- 🌍 疫情全靠"人传人"：只有真实的跨群活跃才会扩散
- 🛡️ 防作弊 / 防刷屏 / 死群保护（7 天无发言不参与传播）齐备
- 📊 烛之瘟疫 t2i 模板渲染（t2i 服务直连）→ 本地 Pillow → 纯文本三级降级
- 🔒 所有数据库操作参数化查询，动态字段走白名单
